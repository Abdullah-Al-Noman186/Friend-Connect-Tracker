

Name of your project
=>Friend Connect Tracker**


A short description
=>Friend Connect Tracker is a React-based personal relationship management app that helps users track how often they communicate with friends. It allows users to log calls, texts, and video interactions, view their history in a timeline, and analyze communication patterns using charts and statistics.



Technologies you used
=>
React.js
React Router DOM
Tailwind CSS / DaisyUI
Recharts (for data visualization)
LocalStorage (for data persistence)


3 key features of your project
=>
1. **Activity Tracking Timeline**
   Logs every call, text, and video interaction with friends and displays them in a clean timeline view.

2. **Search & Filter System**
   Allows users to search and filter activities by friend name or interaction type (call/text/video).

3. **Analytics Dashboard (Stats Page)**
   Visualizes user communication patterns using a Pie Chart, showing distribution of calls, texts, and video interactions.
